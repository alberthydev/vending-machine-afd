# Vending Machine - AFD em JavaScript (Trabalho 01)

Site estático (HTML/CSS/JS) implementando o AFD da vending
machine modelada no JFLAP: moedas de **5, 10 e 25** centavos, produto de
**30** centavos, com um estado de "estouro" (**30+**) para quando o valor
inserido passa do preço.

[Link](https://alberthydev.github.io/vending-machine-afd/)
